# Retail Sales Analysis

## Project Overview
This project analyzes retail sales data using SQL and Power BI to uncover insights into sales trends, customer behavior, and product performance.

## Tools Used
- SQL
- Power BI
- Excel

## Key Insights
- Analyzed sales trends over time.
- Identified top-performing product categories.
- Examined customer demographics by age group and gender.
- Ranked top customers based on total revenue.
- Created an interactive Power BI dashboard for business insights.

## Files
- retail_sales_queries.sql – SQL queries used for analysis.
- Retail_Sales_Dashboard.pbix – Power BI dashboard.
- dashboard.png – Dashboard preview.
